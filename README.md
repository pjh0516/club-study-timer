# 우리 동아리 공부 타이머

정적 웹사이트입니다. GitHub 저장소에 업로드한 뒤 GitHub Pages를 켜면 공개 URL로 접속할 수 있습니다.

## 배포

1. 이 폴더의 파일을 GitHub 저장소의 기본 브랜치에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 소스로 **GitHub Actions**를 선택합니다.
3. `main` 브랜치에 push하면 `.github/workflows/pages.yml`이 사이트를 배포합니다.

현재 기록은 브라우저의 로컬 저장소에 남습니다. 사이트를 온라인에 올려도 기기 간 기록 동기화는 되지 않습니다. 동기화하려면 로그인과 온라인 데이터베이스 연결이 추가로 필요합니다.
